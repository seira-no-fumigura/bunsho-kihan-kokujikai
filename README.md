## 作品について

文章軌範の国字解。松平康国（破天荒斎）が講じた『文章軌範国字解』で、選者の伝記・作家小伝と、侯字集から乎字集までの巻之一〜七の文（放膽文・小心文）を、注解・講説を付けて収める。附録に海保漁村の『漁村文話』が付く。大正 6 年（1917 年）に早稲田大学出版部が『漢籍国字解全書』追補の第 34 巻として出した。国立国会図書館の目次の字のままの見出しが付く（附録の見出しは OCR から付けた）。巻頭の解題・例言・目次（早稲田大学編輯部）は入れていない。

## 底本

- [漢籍国字解全書 : 先哲遺著追補](https://dl.ndl.go.jp/pid/941437)（早稲田大学編輯部 編・早稲田大学出版部・1917年）。国立国会図書館の全文テキスト（OCR）のまま

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
